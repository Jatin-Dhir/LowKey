# LowKey

Keyboard RGB lighting for Windows.

**Download:** grab `LowKeySetup.exe` from the [latest release](https://github.com/Jatin-Dhir/LowKey/releases/latest) and run it.
Windows may say "Windows protected your PC" because the installer isn't certified with Microsoft: click **More info**, then **Run anyway**.

Once installed, LowKey keeps itself up to date.
